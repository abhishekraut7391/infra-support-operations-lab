# Security and Safe Use

This repository is designed for learning and authorized troubleshooting.

- Run scripts only on systems you own or are explicitly authorized to inspect.
- The supplied scripts collect diagnostic information; review them before running in a sensitive environment.
- Do not commit passwords, API keys, private keys, tokens, customer records, production logs, or confidential network details.
- Use least privilege. Do not run commands with `sudo` unless required and approved.
- Do not restart services, change firewall rules, delete files, or modify configuration as part of a read-only investigation.
- Replace hostnames, IP addresses, usernames, and log content with fictional or sanitized examples before publishing.
- Record evidence accurately and distinguish observations from assumptions.
